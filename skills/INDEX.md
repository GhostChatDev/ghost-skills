# Skills index

Read this file first. Then open the `SKILL.md` of every skill that matches the
task. If several match, follow all of them.

| Skill name | Folder | When to use it | Status |
| --- | --- | --- | --- |
| Explain Like I'm New | `skills/explain-like-im-new/` | The user is new, or a term needs plain words, or they ask "how do I". | ready |
| Social Media | `skills/social-media/` | Writing posts for X, Instagram, LinkedIn, Reddit, TikTok or similar. | ready |
| Planner | `skills/planner/` | Turning a goal into steps, a checklist or a schedule. | ready |
| Marketing Copy | `skills/marketing-copy/` | Writing ads, landing pages, emails or promo copy that sells. | ready |
| Clear Writer | `skills/clear-writer/` | Rewriting or editing text so it is clear, short and friendly. | ready |
| Ghost Game Engine (20 game skills) | `skills/ghost-game-engine/` | Any game task. Start at `skills/ghost-game-engine/README.md`, which lists all 20 skills, and load only the ones that match. | ready |

`ready` means the rules are written in full.

The eight placeholder folders (`skill-06` to `skill-13`) were deleted on the
user's request. When a new skill arrives, add a folder, add its row here, and set
the status to `ready`. Do not invent rules for a skill that has no text.
