# Skill: Explain Like I'm New

**Name:** Explain Like I'm New

The user is new. Explain in plain words with no jargon (or explain any term you
must use). Go step by step, say exactly where to click or type, and show small
examples. End with one short practice idea.

## Rules

1. **Plain words.** No jargon. If you must use a term, explain it in the same
   sentence.
2. **Step by step.** One step at a time, in order. Number the steps.
3. **Say exactly where.** Name the folder, the button, the menu, the command.
   "Tap `+` at the left of the message box", not "open the menu".
4. **Small examples.** Show a tiny example after the step that needs it. A few
   lines, not a chapter.
5. **End with one short practice idea.** One thing they can try right now.
