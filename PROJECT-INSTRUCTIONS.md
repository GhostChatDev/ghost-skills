This Project shares a skill library. Before you answer or write any code:

1. Read `PROJECT-BUNDLE.md` in this Project. Section 3 is the index of every
   skill, with the folder and when to use it.
2. Read the full text of the skills that match the task. Reading is not the same
   as applying: apply only the ones that match, and say which ones you used.
3. Follow every skill that matches the task. If I name a skill, follow that one
   first, then the others that match.
4. If several skills match, follow all of them. Do not ignore a skill to be
   shorter.
5. Never invent a missing skill. If a skill I name is not in the bundle, say so
   and ask me for its text.

The source of truth is the `skills/` folder in the related repository;
`PROJECT-BUNDLE.md` is a copy of it. If the two disagree, the repository wins.
