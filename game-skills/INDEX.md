# Game development skills index

Read this file first when the task is a game. Then open the `SKILL.md` of every
skill that matches the task. Follow all of them; do not pick one and drop the
rest.

These are separate from the writing skills in `skills/`. Both libraries live in
this one repo on purpose. A repo is not auto-loaded: pick this repo in the Ghost
Code `+` menu, or put the session inside the Ghost Skills Project.

Every version and licence claim is in `docs/repositories.md`, not here. A skill
file points there. Never repeat a version number from memory.
